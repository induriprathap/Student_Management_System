\# Student Management System



A web-based Student Management System developed using Python and Django to manage student information, attendance, and marks.



\## Project Overview



This project provides a simple platform for managing student records through a Django web application.



Administrators can manage student information, attendance, and marks, while registered students can log in and view their personal information, attendance, and academic marks through a dashboard.



\## Features



\- User registration and login

\- Admin authentication

\- Student CRUD operations

\- Add, edit, and delete student records

\- Student search

\- Pagination

\- Attendance management

\- Marks management

\- Student dashboard

\- Attendance summary and chart

\- Responsive interface using Bootstrap



\## Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- Bootstrap

\- SQLite

\- Django ORM
